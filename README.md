Descrpción: 
ArenaGT es un sistema diseñado para organizar y administrar una copa deportiva en la que participan diferentes equipos y empresas. Permite llevar un registro de los equipos inscritos, organizar encuentros de fútbol sala y baloncesto, programar exhibiciones y consultar los resultados de cada partido. También facilita el seguimiento de los puntos acumulados por los equipos y la organización de las actividades mediante un calendario. Su propósito es mantener toda la información del torneo ordenada y facilitar su desarrollo de una manera sencilla.

Como correr:
javac -d bin src/*.java 
java -cp bin Main
